
# Python Bank Simulator

A simple command-line banking simulator built with Python.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Validate transaction amounts
- Save the balance using JSON
- Preserve the balance between sessions

## Requirements

- Python 3
- No external packages required

## How to Run

```bash
python bank.py
```

## Technologies

- Python
- JSON
- pathlib

## What I Learned

- Functions and conditional statements
- Loops and user input
- Input validation
- JSON file handling
- Persistent data storage

---

This is an educational banking simulation. It is not connected to a real bank.
